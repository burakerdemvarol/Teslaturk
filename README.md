# Teslaturk

## GitHub Pages deployment

- Expected URL: `https://burakerdemvarol.github.io/Teslaturk/`
- Deployment workflow: `.github/workflows/deploy-pages.yml`
- Trigger: automatic on pushes to `main` (and manual via **Run workflow**)

### Required repository setting

In GitHub repository settings, ensure **Pages** is configured to **Build and deployment: GitHub Actions**.
